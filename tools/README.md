# Herramientas auxiliares

| Carpeta | Uso |
| --- | --- |
| [`hojas_calculo/`](hojas_calculo/) | Genera las plantillas de carga de alumnos publicadas en `public/plantillas/`. |
| [`documentacion/`](documentacion/) | Genera la propuesta documental con sus recursos visuales en `assets/`. |

Las herramientas no forman parte del arranque de Laravel. Ejecuta los generadores desde la raíz del repositorio y revisa los archivos que produzcan antes de publicar una plantilla. `generar_propuesta_documental.py` guarda el documento en `output/documentacion/`, fuera de Git.
