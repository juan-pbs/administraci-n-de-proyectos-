# Conversaciones Codex del Sistema

Esta carpeta concentra el contexto de trabajo realizado con Codex para el Sistema Web de Administracion de Proyectos Integradores.

El objetivo es que el proyecto pueda retomarse en otra computadora sin depender de la memoria del chat original.

## Archivos

- `resumen_general.md`: resumen completo del trabajo realizado y decisiones principales.
- `bitacora_cronologica.md`: orden aproximado de los cambios solicitados y aplicados.
- `continuidad_desarrollo.md`: puntos pendientes y recomendaciones para continuar.
- `contexto_tecnico.md`: datos tecnicos del sistema, rutas, modulos, base de datos y comandos.

## Nota Importante

Esta carpeta no contiene una transcripcion literal completa de todos los chats externos, porque Codex solo puede escribir el contexto disponible en este espacio de trabajo y en la conversacion actual. Se incluyo el resumen mas completo posible de lo trabajado, incluyendo documentacion, modelos, login, base de datos, modulos, plantillas y ajustes recientes.
